# VK Музыка: «Микс на двоих» и музыкальный ассистент

Кликабельный прототип двух доработок VK Музыки в рамке телефона. Тестовое задание на стажировку VK «Менеджер продукта».

**Открыть прототип:** https://shizalihova.github.io/vk-music-prototype/

## Что предлагаю

1. **«Микс на двоих».** Общий плейлист с другом из VK, который каждый день собирается из вкусов обоих: процент совпадения, баланс «моё / поровну / друга», отправка другу в Сообщения. Это развитие блока «Слушайте друг друга»: там плейлисты незнакомцев, здесь общий плейлист с конкретным другом.
2. **Музыкальный ассистент.** Отдельная вкладка рядом с обычным поиском. Находит трек по описанию, фото или сцене из фильма, например: «„Кухня“, 2 сезон, 3 серия, когда разбили посуду».
3. **Связка с VK Видео.** Из ответа ассистента можно перейти к сцене в VK Видео, а из плеера узнать, где звучал трек.

## Зачем

- Микс обновляется каждый день, и это повод вернуться в приложение.
- Каждый микс — приглашение друга, а значит органический рост.
- Вопрос «что за песня из сериала?» решается внутри VK, а не в чужих сервисах.
- Один сценарий вовлекает пользователя в два продукта экосистемы.

## Метрики

**North Star:** еженедельное время «социального» прослушивания на пользователя, то есть минуты из миксов на двоих и из треков, найденных ассистентом.

**Микс на двоих**
- Целевая: D7 retention в тесте против контроля.
- Воронка: показ карточки -> выбор друга -> создание -> первое прослушивание -> возврат на D1 и D7.
- Вовлечённость: минуты прослушивания на DAU, доля DAU с активным миксом.
- Рост: K-фактор, D7 у приглашённых пользователей.
- Монетизация: конверсия в подписку у приглашённых.

**Ассистент и VK Видео**
- Целевая: доля успешных поисков (трек включили или сохранили).
- Воронка: запрос -> ответ -> прослушивание -> сохранение -> переход в VK Видео.
- Экосистема: переходы из Музыки в VK Видео и обратно, доля пользователей обоих сервисов за неделю.

**Проверка:** два независимых A/B-теста. Для микса рандомизация кластерами друзей, потому что функция сетевая. Длительность от 2 до 3 недель.

## Что можно пройти в прототипе

- **Микс на двоих:** Главная -> карточка «Микс на двоих» -> выбор друга -> общий плейлист.
- **Обычный поиск:** иконка лупы -> вкладка «Поиск» -> например, «Земфира».
- **Ассистент:** иконка лупы -> вкладка «Ассистент» -> пример с «Кухней».
- **Тема оформления:** иконка в шапке рядом с лупой -> дневная, ночная или системная.

Работает каждая кнопка: плеер, очередь, лайки, действия с треками, уведомления, настройки.

## Ограничения демо

- Ответы ассистента заданы сценарием. Сцены, тайм-коды и название трека из «Кухни» условные. Цвета загруженного фото анализируются по-настоящему.
- Обложки треков нарисованы градиентами, а не взяты из каталога.
- Распознавание музыки по звуку сцены — продуктовая гипотеза. Для неё нужен доступ к звуковым дорожкам серий в VK Видео.
